# 图片放置说明

把你的照片按下面的文件名放进 `public/images/` 目录即可，网站会自动显示：
（文件名必须完全一致，包括扩展名；支持 .jpg / .png / .webp）

| 文件名 | 用途 |
| --- | --- |
| `life.jpg` | 首页右侧的生活照（对应你本地的 1.jpg） |
| `origin-elementary.jpg` | Origin 时间轴：电报路小学（2.2.jpg） |
| `origin-junior.jpg` | Origin 时间轴：万州二中 初中（2.3.jpg） |
| `origin-senior.jpg` | Origin 时间轴：万州二中 高中（2.4.jpg） |
| `origin-university.jpg` | Origin 时间轴：湖南大学（2.5.jpg） |

简历：把你的 PDF 命名为 `resume.pdf` 放在 `public/` 根目录（即 `public/resume.pdf`），
首页“下载简历”和弹窗里的“查看/下载 PDF 简历”就会指向它。

> 在没放真实照片前，页面会用带文字的渐变色块占位，不会显示裂图。
